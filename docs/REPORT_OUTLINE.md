## 0. 封面與摘要
- 題目、姓名、學號、日期
- 一段話摘要：用 vibe coding 與 AI 查證，製作一款教人出境流程的闖關遊戲

## 1. 動機與目標
- **動機**：〔你的故事，例如第一次出國的緊張、喜歡小小兵〕。出境規定零散又常變動（行動電源、申報、入境表格），常見資訊以文字散佈在新聞與公告，不易記憶。
- **目標**：把「看規定」變成「玩遊戲」，並讓玩家結束後得到可複習的出境手冊。
- **對象**：第一次出國的旅客；展示對象為授課老師。

## 2. 專案內容與流程（概念圖）
- 放入 `images/01_game_flow.png`：8 個關卡依真實動線排列，前一關沒過關，柵欄不開。
- 放入 `images/02_question_loop.png`：每關抽 3 題、答對鼓勵、答錯扣血並解釋、愛心歸零只重打該關。
- 遊戲截圖：標題畫面、選角、地圖、對話、結尾、出境手冊（〔自行截圖〕）。
- 設計重點：
  - 以**桃園機場真實動線**設計：報到→託運→安檢→證照查驗→免稅店→登機門→機艙。
  - **情緒價值**：答對有小小兵的鼓勵與補充知識；答錯不責備，耐心解釋。
  - **每次遊玩題目不同**：題庫 84 題，每關隨機抽題並記住玩過的題目，下次優先抽新題。

## 3. 生成式 AI 的使用（本課核心）
放入 `images/04_ai_workflow.png`。

### 3.1 文字生成：題庫
- 方法：Claude 依關卡主題搜尋官方或權威來源，再生成題目、四個選項、解析與小小兵口吻回應；每題附**來源網址與查證日期**。
- Prompt／指令設計重點：限定「持台灣護照的旅客」、每國最多 4 題、答錯要耐心解釋、規定要以最新資料為準。
- **為什麼預先生成，而非遊玩時即時生成？**
  1. GitHub Pages 是靜態網站，API Key 放前端會外洩。
  2. 出入境規定錯誤會誤導旅客，預先生成才能先查證、再人工審閱。
  3. 離線也能玩，結果可重現，方便展示。

### 3.2 AI 幻覺與錯誤的處理（可作為報告亮點）
| 發現的問題 | 處理方式 |
|---|---|
| 初稿把出境稱為「過海關」 | 出境主要是移民署證照查驗；另補上海關出境申報（現金、黃金） |
| 初稿「託運後務必等行李過 X 光」 | 找不到桃園統一公告，改成「依地勤人員指示」並標註 |
| 「護照一律要有 6 個月效期」 | 實際因目的地而異，改成各國題目分別查證 |
| 網路文章寫韓國 K-ETA 2026 年起必辦 | 與官方消息不符（豁免至 2026-12-31），採官方並記錄 `expires` |
| 英國 ETA 費用多數舊文章仍寫 10 英鎊 | 採最新 16 英鎊 |
| 臉部辨識報到屬松山機場 | 不寫成桃園的流程 |
| 單一新聞來源（日本退稅、離境稅等） | 標記 `recheck`，交件前再核對 |
- 品質機制：來源網址、查證日期、`recheck`（待再確認）、`expires`（規定期限）、人工審閱。
- 統計：84 題、45 個不同來源網址、7 題待再確認（見 `SOURCES.md`）。

### 3.3 程式生成：vibe coding
- 全程用自然語言提出需求，由 Claude 撰寫 HTML／JavaScript。
- 迭代紀錄：最小可玩版 → 擴充題庫 → 角色改為「職位＋姓名」→ 地圖美化 → 地面標線、行李推車、路人。
- 驗證：Playwright 自動走完 8 關並產生手冊，無程式錯誤；截圖檢查畫面。

### 3.4 圖像處理
- 角色圖：由我蒐集；Claude 以連通區域演算法去除白底。第一次去背誤刪護目鏡，目視檢查後調整門檻重做。
- 地圖場景：以 Canvas 程式繪製（櫃檯、輸送帶、X 光機、貨架、窗戶、座椅）。
- **誠實說明與可延伸方向**：目前圖像並非由圖像生成模型產生。若老師要求包含圖像生成，可用圖像生成工具產生標題插圖、出境手冊封面或場景背景，放入 `assets/bg/` 後替換即可。〔請先向老師確認評分標準〕

## 4. 技術架構
放入 `images/03_architecture.png`。
- 前端：HTML5 Canvas（地圖、角色、路人）＋ DOM（對話框、手冊）＋原生 JavaScript，單一檔案。
- 資料：JSON 題庫 → `build_data.py` 合併成 `questions.js`（可雙擊開啟，不需伺服器）。
- 儲存：`localStorage` 記住答過的題目。
- 工具：Python（合併資料、去背、畫概念圖）、Playwright（自動測試）。
- 部署：GitHub Pages 或本機開啟；無後端、無 API Key。

## 可能被問的問題與答法
- **為什麼不即時呼叫 AI？**　靜態網站會外洩金鑰；出入境規定需先查證；可離線穩定展示。
- **怎麼知道題目是對的？**　每題附來源與日期，不確定的標記待確認，並有人工審閱。
- **AI 幫你做了什麼、你做了什麼？**　AI 負責搜尋整理、生成題目與程式；我負責規格、角色素材、取捨與驗收。
